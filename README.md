# Слияние таблиц продаж

Консольная утилита на Python, которая собирает таблицы продаж от разных менеджеров в одну, проверяет и чистит данные
и строит отчёт. На входе файлы `.csv`, `.xlsx`, `.xls` (можно вперемешку и целыми папками), на выходе три файла Excel:

- объединённая таблица продаж с добавленным столбцом «Выручка»;
- отчёт: общая выручка, число заказов, средний чек, продажи по менеджерам и по месяцам, два графика;
- таблица ошибок: каждая отклонённая строка с указанием файла, номера строки и причины.

Стек: Python 3.10+, pandas, openpyxl, xlrd, rich, pytest.

## Установка

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

Для запуска тестов нужен `requirements-dev.txt` (см. раздел «Тесты»).

## Запуск

```bash
python merge.py ПУТЬ [ПУТЬ ...] [-o ПАПКА] [--no-color]
```

Пути можно перечислять вперемешку: отдельные файлы и папки. Из папки берутся только `.csv`, `.xlsx`
и `.xls` (вложенные папки не обходятся, временные файлы Excel `~$...` пропускаются).

Пример:

```bash
python merge.py sales/ extra/old_sales.xls -o результаты
```

| Параметр | Назначение |
|---|---|
| `-o`, `--output` | папка для результатов (по умолчанию `output`) |
| `--no-color` | не использовать цвета в консоли |
| `-h`, `--help` | справка |

## Что получится

В папке результатов создаются три файла (дата запуска в имени):

- `merged_sales_ГГГГ-ММ-ДД.xlsx`: объединённая таблица с добавленным столбцом «Выручка»;
- `report_ГГГГ-ММ-ДД.xlsx`: сводка, продажи по менеджерам и по месяцам, два графика;
- `errors_ГГГГ-ММ-ДД.xlsx`: все отклонённые строки с причиной (если ошибок нет, в файле строка «Ошибок нет»).

Существующие файлы не перезаписываются: при повторном запуске в тот же день у всех трёх файлов
появляется общий суффикс `_2`, `_3` и так далее.

## Пример и тестовые таблицы

В папке `examples/sales/` лежат три небольшие таблицы (16–18 строк) для проверки работы. В каждую намеренно добавлены
типичные ошибки:

| Файл | Формат | Особенности | Заложенные ошибки |
|---|---|---|---|
| `1_aleksey.csv` | CSV, UTF-8, разделитель `,` | имя менеджера в разном регистре и с лишними пробелами | отрицательная цена (1016), количество 0 (1017), пустая цена (1018) |
| `2_maria.xlsx` | Excel | настоящие даты Excel, номера заказов числами | дубль номера 1005 из файла Алексея, несуществующая дата 31.02.2026 (2016), пустой товар (2017) |
| `3_ivan.csv` | CSV как из русского Excel: cp1251, разделитель `;` | цены вида `3 500,00`, даты `ДД.ММ.ГГГГ` и `ДД/ММ/ГГГГ` | цена «abc» (3015), пустой менеджер (3016) |

Запуск:

```bash
python merge.py examples/sales -o output
```

Ожидаемый результат:

- принято 43 строки из 51, отклонено 8 (пустое поле: 3, недопустимое значение: 2, неверный формат: 2, дубликат: 1);
- общая выручка 744 050,00, средний чек 17 303,49;
- менеджеры по выручке: Мария (370 000,00), Иван (235 700,00), Алексей (138 350,00);
- «алексей» и «  Алексей  » объединены в «Алексей»;
- код возврата `1`, так как часть строк отклонена.

Эти же числа проверяет автотест `tests/test_examples.py`.

## Какие столбцы нужны

| Столбец | Допустимые заголовки |
|---|---|
| Номер заказа | Номер заказа, № заказа, ID заказа, order_id |
| Дата | Дата, Дата заказа, date |
| Товар | Товар, Наименование, Название товара, product |
| Категория | Категория, category |
| Количество | Количество, Кол-во, quantity |
| Цена | Цена, Цена за единицу, price |
| Менеджер | Менеджер, Сотрудник, manager |

Регистр и пробелы по краям в заголовках не важны, порядок столбцов любой, лишние столбцы игнорируются.
В Excel читается только первый лист.

## Форматы значений

- **CSV:** кодировка UTF-8 (с BOM или без) или cp1251, разделитель `,` или `;` определяется автоматически.
- **Дата:** `ГГГГ-ММ-ДД`, `ДД.ММ.ГГГГ`, `ДД/ММ/ГГГГ` или настоящая дата Excel. Запись `03/04/2026` читается как
  3 апреля (день/месяц). В результатах везде `ГГГГ-ММ-ДД`.
- **Цена:** `3500.00`, `3500,00`, `3 500,00`; отрицательная цена ошибка, ноль допустим.
- **Количество:** целое число (`2.0` принимается); ноль и отрицательные значения ошибка.
- **Номер заказа:** читается как текст, ведущие нули сохраняются (`00123`); `1001` в CSV и число `1001` в Excel
  это один и тот же заказ.

## Правила очистки

- Пробелы по краям обрезаются, повторные схлопываются; полностью пустые строки удаляются.
- Дубли по номеру заказа: остаётся первая строка (в порядке файлов и строк), остальные попадают в ошибки.
- Имена менеджеров сравниваются без учёта регистра; в результатах остаётся написание, встреченное первым.
- Строки с ошибками не попадают ни в объединённую таблицу, ни в отчёт.

Типы ошибок: «Нет столбцов», «Файл не прочитан», «Пустое поле», «Неверный формат», «Недопустимое значение»,
«Дубликат».

## Коды возврата

| Код | Значение |
|---|---|
| `0` | все строки приняты |
| `1` | часть строк или файлов отклонена, результаты созданы |
| `2` | критическая проблема: файлы не найдены, нет принятых строк (создаётся только файл ошибок) или не удалось записать результат |

## Структура проекта

```
merge.py               точка входа
sales_merger/
  discovery.py         поиск файлов
  loader.py            чтение csv / xlsx / xls
  columns.py           сопоставление заголовков
  validator.py         разбор дат, цен, количества и проверка строк
  cleaner.py           очистка, дубли, имена менеджеров
  pipeline.py          обработка файлов без вывода в консоль
  metrics.py           выручка, средний чек, группировки
  writer.py            запись трёх Excel-файлов и графиков
  cli.py               аргументы, вывод в консоль, коды возврата
tests/                 автотесты (pytest)
examples/sales/        тестовые таблицы
```
